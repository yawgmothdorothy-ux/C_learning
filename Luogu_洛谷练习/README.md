例如运行自己的约瑟夫实现：

```bash
cd Josephus_约瑟夫问题
gcc -std=c99 -Wall -Wextra P1996.c -o P1996
printf '5 3\n' | ./P1996
```

正确淘汰顺序为 `3 1 5 2 4`。编译得到的可执行文件保留在本地，由仓库 `.gitignore` 排除。
