# 班级成绩分析器：C 语言结构体与指针练习

这是一个命令行学习项目：录入一个班级的三科成绩，计算个人总分和平均分、全班平均总分、第一名以及三科全部及格人数，并按学号查询学生。

项目从“用一个结构体保存统计结果”扩展到“用结构体数组保存多个学生”，重点是理解数组、结构体、指针、函数参数和动态内存如何配合。这里记录的不只是程序用法，也包括编写过程中遇到的问题和后续可改进的地方。

## 文件与编译运行

```text
StudentScores_学生成绩/ClassAnalysis_班级成绩分析/
├── class_score.c     # main：输入、内存管理、班级统计、查询和输出
├── student_score.c   # calculate_total：计算一个学生的总分和平均分
├── student_score.h   # 结构体类型和函数声明
├── .gitignore        # 排除本目录的 program 和目标文件
└── README.md
```

需要 GCC 或兼容的 C 编译器。在仓库根目录运行：

```bash
cd StudentScores_学生成绩/ClassAnalysis_班级成绩分析
gcc -std=c11 -Wall -Wextra -Wpedantic -g class_score.c student_score.c -o program
./program
```

必须同时编译两个 `.c` 文件。包含 `student_score.h` 只让编译器知道类型和函数声明，不会自动编译 `student_score.c`；只编译入口文件会缺少 `calculate_total` 的实现。

如果使用 VS Code，编译任务应包含本目录的两个 `.c` 文件，启动配置的 `program` 应指向本目录生成的可执行文件。打开哪个源文件，并不自动决定 F5 启动哪个项目。

## 输入与输出

依次输入：

1. 学生人数，范围为 `1～100`。
2. 每个学生的四个整数：`学号 语文 数学 英语`，三科成绩范围均为 `0～100`。
3. 最后输入一个需要查询的学号。

程序按空白分隔读取，换行主要用于方便阅读。练习约定使用互不重复的正整数作为学号；当前版本尚未校验学号的正数性与唯一性。输入的整数应在当前平台的 `int` 表示范围内。

示例输入：

```text
4
1001 80 90 70
1002 95 85 90
1003 60 55 75
1004 90 90 90
1003
```

对应输出：

```text
学生ID: 1001, 总分: 240, 平均分: 80.00
学生ID: 1002, 总分: 270, 平均分: 90.00
学生ID: 1003, 总分: 190, 平均分: 63.33
学生ID: 1004, 总分: 270, 平均分: 90.00
被咨询学生ID: 1003, 总分: 190, 语文: 60, 数学: 55, 英语: 75, 平均分: 63.33
平均总分: 242.50
最高分学生ID: 1002, 总分: 270
所有科目及格人数: 3
```

这里的个人平均分是三科总分除以 3；全班平均总分是所有学生总分之和除以人数。总分并列时选择最先输入的学生。查询不存在的学号会输出“未找到…号学生”。

## 一、构思时的知识问题

### 1. 一个结构体怎么保存所有学生？

先用结构体描述一个学生，再用数组保存多个学生：

```c
typedef struct {
    int id;
    int chinese;
    int math;
    int english;
    int total;
} StudentScore;
```

这只是定义类型。创建一个学生和三个学生分别是：

```c
StudentScore student = {0};
StudentScore students[3] = {0};
```

可以与整数数组对照：`int a[3]` 的每个元素是整数；`StudentScore students[3]` 的每个元素是完整的学生结构体。

```text
students[0] → id、chinese、math、english、total
students[1] → id、chinese、math、english、total
students[2] → id、chinese、math、english、total
```

人数在运行时才知道，所以项目采用动态分配。下面是与现有写法等价、无需强制转换的 C 写法：

```c
StudentScore *students = malloc((size_t)student_count * sizeof(*students));
```

`sizeof(*students)` 是一个学生结构体的大小；乘以人数，才是整个数组所需的空间。`malloc` 分配的内容没有初始化，必须先成功读入成员，再使用它们。申请失败返回 `NULL`。

### 2. 结构体数组与结构体内部的数组有什么区别？

当前项目用 `students[i].math` 表示第 `i` 个学生的数学成绩。也可以在结构体里定义 `int scores[3]`，那就通过 `students[i].scores[1]` 访问某一科。本项目选择科目名称作为成员名，便于初学时理解。

### 3. 下标和学号是不是一回事？

不是。`students[0]` 表示数组里的第一个学生，而其学号可能是 `1001`。因此，不能直接用 `students[1001]` 查找学号为 `1001` 的学生，那可能访问数组范围之外的内存。

当前程序逐个比较 `students[i].id`，找到后退出循环。`found` 记录是否找到，用于决定要不要显示“未找到”的提示。

### 4. 为什么函数能修改 main 中的学生？

实际调用是：

```c
calculate_total(&students[i], &total_scores_one_student[i],
                &average_one_student[i]);
```

三个参数都是地址：当前学生的地址、总分输出位置的地址、平均分输出位置的地址。函数接收这些地址：

```c
int calculate_total(StudentScore *student,
                    int *total_scores_one_student,
                    double *average_one_student);
```

C 的参数按值传递，这里复制的是地址值。指针参数仍指向调用方的原数据，因此下面的赋值会修改调用方的数据：

```c
student->total = student->chinese + student->math + student->english;
*total_scores_one_student = student->total;
*average_one_student = (double)student->total / 3.0;
```

结构体指针并不是特殊的“传送机制”；它和 `int *` 一样保存地址，只是指向的对象类型不同。两个函数里的变量也不需要同名。

当前函数成功返回总分，空指针时返回 `-1`。返回总分与通过指针写出总分存在重复，这是当前练习版本的设计，后续可以简化。

## 二、语法上容易混淆的问题

| 写法 | 在本项目中的含义 |
|---|---|
| `StudentScore` | 类型名 |
| `StudentScore student` | 一个结构体变量 |
| `StudentScore *student` | 一个结构体指针 |
| `students[i]` | 数组中的一个结构体 |
| `students[i].math` | 该结构体的数学成绩 |
| `&students[i]` | 该结构体的地址 |
| `&students[i].math` | 该数学成绩成员的地址 |
| `student->total` | 通过指针访问成员，等价于 `(*student).total` |
| `*total_scores_one_student` | 通过整数指针访问它指向的整数 |

### 1. 为什么 scanf 要加 &，printf 却不用？

`scanf` 要把值写入变量，需要目标地址；`printf` 打印变量的值：

```c
scanf("%d", &students[i].math);
printf("%d\n", students[i].math);
```

当前项目读取 `int` 使用 `%d`，打印 `double` 使用 `%.2f`。如果用 `scanf` 读取 `double`，应使用 `%lf` 并传入 `double *`。格式与参数类型必须匹配。

输出的标签顺序也必须与参数顺序对应。本次检查修正过“英语、数学”标签与实际成绩位置相反的问题：这种错误可能编译通过，但会误导读者。

### 2. 检查输入时，为什么不能再读一遍？

曾出现过以下写法：

```c
scanf("%d", &student_count);
if (scanf("%d", &student_count) != 1) {
    /* ... */
}
```

第二次 `scanf` 不会检查上次结果，它会消耗下一份输入，把第一个学号当成人数。正确方式是把读取与检查合在一次调用中：

```c
if (scanf("%d", &student_count) != 1 ||
    student_count < 1 || student_count > 100) {
    printf("学生人数输入错误\n");
    return 1;
}
```

`||` 从左到右短路求值：读取失败时，不再继续使用尚未赋值的人数做范围比较。

### 3. 为什么查询学号还要检查？

录入学生信息和输入查询学号是两次独立读取。学生资料正确，不代表稍后输入的查询内容也是整数。

- `scanf(...) != 1`：检查查询输入有没有成功读成一个整数。
- 查找循环：检查这个整数对应的学号是否存在。

输入 `abc` 是格式错误；输入不存在的 `9999` 是查无此人。不是重复检查已有成绩。

### 4. 平均值为什么需要类型转换？

```c
statistics.average_total = (double)total_scores / student_count;
```

先转换一个操作数，再做除法，可以保留小数。直接用两个整数相除，会先进行整数除法，即使之后赋给 `double`，丢失的小数也不会恢复。

当前代码末尾的 `+0.0` 是多余的；`average_one_student[i]` 本身已是 `double`，打印时无需再转换；其地址本身已是 `double *`，调用时也无需强制转换。这些是后续可独立清理的小改动。

### 5. fprintf(stderr, ...) 是什么？

`printf` 默认写入标准输出 `stdout`；`fprintf(stderr, ...)` 把错误提示写入标准错误流。默认通常都显示在终端，但运行 `./program > result.txt` 时，标准输出进入文件，标准错误仍可显示在终端。当前项目的内存分配错误使用 `stderr`，输入错误仍使用 `printf`。

## 三、算法与初始化

1. 对每个学生读取四个整数，检查成绩范围。
2. 调用 `calculate_total`，计算三科总分和平均分。
3. 累加班级总分，并比较最高总分。
4. 用三个 `>= 60` 条件通过 `&&` 连接，统计三科全部及格人数。
5. 计算全班平均总分，读取查询学号，再顺序查找学生。

`highest_score` 初始化为 `-1`，因为合法总分最小为 `0`，第一个学生一定能更新最高分。使用 `>` 而不是 `>=`，让后来的并列学生不会替换先前的第一名。

`StudentStatistics statistics = {0};` 初始化统计成员，`found = 0` 初始化查找状态；总分累加器也从零开始。

在最多 100 人、每科最多 100 分的限制下，个人总分最多 300，全班总分最多 30000，当前使用的 `int` 足以保存这些统计值。

计算和查询各遍历一次学生数组，时间复杂度均为 O(n)。当前三个动态数组总体占用 O(n) 空间。

## 四、边界与内存管理

当前已处理：

- 人数读取失败，或人数不在 `1～100`。
- 学生信息未成功读到四个整数。
- 成绩小于 0 或大于 100。
- 查询学号未成功读成整数。
- 查询学号不存在。
- `malloc` 分配失败。
- 正常结束及分配成功后的输入错误退出时释放内存。

分配顺序是总分数组、平均分数组、学生数组。某一步失败，只释放之前已经成功分配的内存；正常结束释放全部三块。指针传给函数不代表所有权转移，本项目由 `main` 负责统一释放。

需要区分“输入尚未完成”和“输入结束”：在交互终端少输入几个整数后按回车，`scanf` 可能继续等待，回车不是文件结束标志。测试不完整输入时可使用输入文件或管道，在输入结束后检查是否报错。Linux 终端也可在适当位置用 Ctrl+D 表示输入结束。

## 五、当前限制与后续小提交

当前版本是学习用命令行程序，还存在以下明确限制：

- 未检查学号是否为正数或重复；重复时查询返回最先匹配的学生。
- `%d` 适合本练习约定的普通整数输入。超出 `int` 范围的数字不能仅靠返回值检查可靠处理；若要严格解析任意文本，可进一步学习 `fgets`、`strtol` 和范围检查。
- 按空白读取，不严格限制每行恰好四个字段；查询后的多余输入不会继续处理。
- 总分既保存在 `students[i].total`，也保存在单独的总分数组里；平均分也可以按需计算。后续可减少重复数据和内存申请。
- 班级统计和查找目前在 `main` 中，之后可分别提取为函数。当前不包含排序、文件保存或多次查询菜单。

建议一次只完成一个改动：先保证正确性，再清理重复转换和统一缩进，再简化数据结构，最后扩展功能。每次提交前重新编译，并运行正常与错误输入测试。
